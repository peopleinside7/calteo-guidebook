이 웹사이트를 한 번에 만든 프롬프트

강의 중 시연한 "3대 AI 비교 웹사이트"를 만든 실제 프롬프트입니다. 여러 번 주고받은 대화를 하나의 완성형 프롬프트로 되돌린 것 — 역할·맥락·목표·형식이 다 들어가면 이렇게 한 번에 나옵니다.

프롬프트 · 웹사이트 제작
너는 30년 경력의 UX/UI 디자이너이자 웹개발자, 기업교육 전문가, AI 리터러시 강사다.

나는 직장인을 대상으로 생성형 AI 활용 교육을 진행한다. 이번 교육에서 사용할 수 있도록 ChatGPT · Google Gemini · Anthropic Claude 3가지 AI를 비교하고 실제 업무에 어떻게 활용하는지를 보여주는 완성도 높은 웹사이트를 html로 제작해줘.

단순한 기능 소개 사이트가 아니라, 실제 회사 업무에 AI를 적용하는 방법을 이해시키는 AI 리터러시 교육용 웹사이트로 만들어라. 핵심 메시지는 "어떤 AI가 가장 좋은가"가 아니라 "어떤 업무에 어떤 AI를 사용해야 하는가"이다.

디자인은 다크 모드 · 미니멀 · 기업용. ChatGPT는 Green, Gemini는 Blue, Claude는 Orange. 단, 위 내용을 사실처럼 단정하지 말고 웹 검색으로 현재 공식 기능인지 확인한 뒤 최신 정보로 수정한다.

STEP 1~2에서 앱을 만들고 링크를 복사했다면(7분), 내 업무에 맞게 기능 1가지를 추가하고(5분), 패들렛에 공유해 다 함께 열어봅니다(6분). 제출 — 패들렛 「7교시 · 나만의 To-Do 앱」 · 제목 「이름 / 내가 추가한 기능」

  1. 공유할 패들렛 보드 접속 (padlet.com/starkj79/ai)
  2. 빈 바탕화면 더블 클릭 또는 우측 하단 [ + ] → 새 게시물 창
  3. 입력창 하단 [ 🔗 링크 아이콘 ] 클릭 → 복사한 앱 URL 붙여넣고 엔터
  4. 제목 입력 — 「이름 + 내가 추가한 기능」 (예: 홍광준 / 거래처별 분류 추가) → [ 발행 ]
  5. 발행된 내 게시물의 링크 상자 클릭 → 새 탭에서 내 앱 실행, 바로 할 일 입력해 보기
기능 추가 요청 예시 (AI Studio 입력창)
거래처별로 분류해줘
마감일 입력을 추가해줘
